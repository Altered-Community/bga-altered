The `misc` folder contains some tools to use to update files in this repository.

### extract-starter-decks.py

This `python` script lets you update the starter decks from a CSV file.

The file is expected to have one deck per hero, containing the decklist, author and a short description.

The script will update the definitions files in `modules/php/Cards/StarterDecks/` and the JavaScript metadata file in `modules/js/StarterDecks.js`.

Update the `starter-decks.csv` file at the root of the repository, the re-run this script with the command
```
python misc/python-tools/extract-starter-decks.py
```

Note: This script was fully generated by AI. Use at your own risk.
