# Altered Re:Union BGA project

Code base of the Re:Union version of Altered on BGA originally made by Equinox.

To access the game on BGA: [here](https://boardgamearena.com/gamepanel?game=altered). Up to 19/05/2026, the game is still maintained by the Equinox team.
On 20/05/2026, the game will switch to Re:Union One
